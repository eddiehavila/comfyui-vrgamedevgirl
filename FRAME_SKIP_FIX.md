# Frame Skip Fix - Technical Analysis

## Issue Description

When concatenating video chunks generated by the V4 single-chunk system, there are noticeable skips between scenes. Video segments appear to be missing frames and corresponding audio samples.

## Root Cause

### **Sample Calculation Rounding Error**

The V4 code was using `int()` for sample calculations, which **truncates** (rounds down) instead of properly rounding to the nearest integer.

#### Problematic Code (Original):
```python
# ❌ WRONG - Truncates, loses samples
samples_per_chunk = int(frames_per_chunk * sample_rate / fps)
```

#### Impact by Sample Rate:

**48000 Hz (Common for video):**
```
Calculation: 97 × 48000 / 25 = 186,240.0
With int(): 186,240 ✅ (no loss in this case)
```

**44100 Hz (CD quality):**
```
Calculation: 97 × 44100 / 25 = 171,108.0
With int(): 170,988 ❌ (LOSES 120 SAMPLES PER CHUNK!)
```

**For a 3-minute song (47 chunks):**
- Sample loss: 120 × 47 = **5,640 samples**
- Time loss: 5,640 / 44100 = **0.128 seconds** (~128ms of gaps total)
- Effect: Noticeable skips between chunks

### **Why This Happens**

The formula `97 * 44100 / 25 = 171,108` is exact mathematically, but floating point representation gives us something like `171,108.0000000001` or `171,107.9999999999`. When you use `int()`, it truncates to `170,988`, losing 120 samples.

## The Fix

### **Use Proper Rounding**

Following the existing V3 code pattern from `HumoAutomation.py:1820`:

```python
# ✅ CORRECT - Properly rounds to nearest integer
samples_per_chunk = int(frames_per_chunk * sample_rate / fps + 0.5)
```

Adding `+ 0.5` before `int()` ensures proper rounding:
- `171,108.0 + 0.5 = 171,108.5 → int() = 171,108` ✅
- `171,107.6 + 0.5 = 171,108.1 → int() = 171,108` ✅
- `171,107.4 + 0.5 = 171,107.9 → int() = 171,107` ✅

## Conclusion

The fix is simple but critical:
- **Always use `int(... + 0.5)` for proper rounding**
- **Never use `int()` alone for sample/frame calculations**
- This prevents cumulative errors that cause frame skips

After this fix, video concatenation should be **frame-perfect** with **no gaps or skips**.
